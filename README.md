# VoiceChanger

실시간 음성변조 + 녹음 데스크톱 앱 (Electron, 무의존성 Web Audio).

## 기능

- **실시간 변조**: 마이크 입력을 즉시 변조해 헤드폰으로 모니터링
- **프리셋 8종**: 원본 · 헬륨 · 저음 괴물 · 로봇 · 외계인 · 동굴 에코 · 무전기 · 다람쥐
- **글로벌 단축키**: `Ctrl+Alt+1~8` 프리셋 전환, `Ctrl+Shift+1~9` 큐 발사, `Ctrl+Alt+R` 녹음, `Ctrl+Alt+B` 원본 통과
- **믹서**: 입력/출력 게인, 노이즈 게이트, 3밴드 EQ, 하이/로우패스
- **이펙트**: 피치(±12반음, 그래뉼러 워크릿), 링모듈레이터(로봇), 디스토션, 에코, 리버브
- **녹음**: 변조된 소리를 WAV로 저장 (`문서/VoiceChanger녹음`), 앱 내 재생/삭제
- **역재생**: TTS 바의 "◀ 역재생" 토글을 켜면 TTS·큐·대본·등록 큐가 전부 거꾸로 재생됨 (자막 없음). 녹음 파일 목록의 ◀ 버튼은 그 파일을 거꾸로 + 변조 이펙트를 걸어 재생 — 거꾸로 말하기 챌린지는 ● 녹음 → 정지 → ◀ 두 클릭이면 됨. ◀ 재생 중에 ● 녹음을 누르면 뒤집힌 소리를 새 파일로 저장 가능
- **TTS**: 텍스트 입력 → 음성 합성 → **변조 이펙트가 그대로 적용**되어 재생·녹음. 목소리 선택 + 속도 조절
  - **자연스러운 음성 (인터넷)**: Edge 신경망 TTS — 한국어 3종(선히·인준·현수) + 다국어 음성 6종(에이바·엠마·앤드류·브라이언·세라피나·레미, 한국어도 읽음). 무료, API 키 불필요
  - **ElevenLabs (인터넷 · 유료)**: ⚙ 설정에 API 키를 넣으면 계정의 목소리(기본+클론)가 목록 맨 위에 나타남. **글자 단위 타임스탬프를 받아 Edge처럼 자막이 정밀 동기화**됨. 모델 선택: Multilingual v2(품질) / Turbo v2.5(절반 가격) / Flash v2.5(최저가). 키는 localStorage에만 저장되고 api.elevenlabs.io 외에는 전송되지 않음
  - **기기 내장 음성 (오프라인)**: Windows SAPI / macOS say
  - **로컬 엔진 (직접 설치 · 오프라인)**: TTS 바의 ⚙ 버튼에서 서버 주소 등 설정
    - **수퍼토닉**: `pip install supertonic` → `supertonic serve` (기본 127.0.0.1:7788). 목소리 M1~M5/F1~F5, 한국어 포함 31개 언어, CPU에서도 빠름
    - **GPT-SoVITS (목소리 클론)**: [통합패키지](https://github.com/RVC-Boss/GPT-SoVITS) 폴더에서 `api_v2.py` 실행 (기본 127.0.0.1:9880). 3~10초 참조 음성(wav) 경로 + 그 음성이 말한 내용을 ⚙ 설정에 입력하면 그 목소리로 말함
    - 로컬 엔진과 기기 내장 음성은 단어 타임스탬프가 없어 자막이 재생 길이 기준 **추정 동기화**됨 (글자 수 비례 + `/` 쉼 가중치). Edge 음성만 정밀 동기화
    - 보안: 로컬 TTS 프록시는 127.0.0.1/localhost 주소만 허용
  - 신경망 TTS가 403으로 실패하기 시작하면 `renderer/edge-tts.js`의 `GEC_VERSION`과 `main.js`의 User-Agent를 최신 Edge 버전으로 올릴 것 (edge-tts 프로젝트의 constants 참고)
- **자막**: 자연스러운 음성 선택 시 말하는 속도에 맞춰 단어가 실시간 하이라이트되는 자막 표시(WordBoundary 기반). TTS 바의 "자막" 체크박스로 켜고 끔
- **대본 (방송용)**: 파트별 대사를 줄 단위로 만들어 두고 누르면 **음성 + 자막(오버레이 포함)이 즉시 함께 재생**됨
  - **📄 대본 붙여넣기** — 전체 대본을 한 번에 붙여넣으면 한 줄이 대사 하나가 됨
  - **줄마다 공백시간(초)** 지정 — 그 줄이 끝나고 다음 줄까지 쉬는 시간. "기본 공백"으로 새 줄의 기본값 설정
  - **▶ 재생** — 첫 줄부터 공백시간에 맞춰 자동으로 이어서 재생 (⏹ 정지 또는 `Esc`로 중단, 공백 중에도 즉시 멈춤)
  - **⚡ 준비** — 음성을 미리 생성해 캐시. 준비된 줄은 초록 점, 발사 지연 0에 가까움(실측: 준비 0.7초 → 발사 0ms)
  - 줄을 직접 클릭하거나 글로벌 단축키 `Ctrl+Shift+1~9`로 개별 발사(자동재생 중이면 수동이 우선). 목소리·속도를 바꾸면 다시 준비 필요 표시
- **등록 큐 (🎯 탭)**: 완성한 대본 전체를 "💾 큐로 등록"으로 이름 붙여 저장. 등록 큐 탭에는 저장된 큐들이 **클릭 가능한 카드 버튼으로만** 표시되어, 클릭 한 번에 대본 전체가 공백 설정대로 자동 재생됨(재생 중 다음 줄을 미리 생성해 끊김 없음, 재재생은 캐시로 즉시). 같은 이름으로 등록하면 덮어쓰기, ⏹ 정지 또는 `Esc`로 중단
- **끊어읽기 + 자막 구분**: TTS 입력에 `/` 를 넣으면 (1) 그 자리에서 쉬어 읽고 (2) **자막도 그 자리에서 줄이 나뉨**. `//` 는 더 길게 쉼. 즉 자막을 원하는 대로 직접 끊어 표시. Edge는 문장부호(쉼표/마침표)로 쉼 변환, macOS는 `[[slnc]]`, Windows SAPI는 문장부호. 자막에는 쉼 기호가 안 나타남
- **자막 오버레이 (OBS용)**: 앱이 `http://localhost:8103/overlay` 를 띄움. OBS/vMix **브라우저 소스**에 이 주소를 넣으면 자막이 `/` 로 나눈 구간대로 실시간 표시됨(배경 투명 — 크로마키 불필요). 오버레이에서는 **말하는 대로 단어가 하나씩 차례로 나타남**
- **자막 스타일**: 앱 하단 "🎨 자막 스타일" 바에서 가로위치(왼쪽·가운데·오른쪽) / 세로위치(위·가운데·아래) / 배치(가로로·세로로 쌓기·세로쓰기) / **폰트(한글 프리셋 8종+직접 입력) / 굵기(보통~블랙)** / 크기 / 강조색 / 차례로 나타내기를 설정하면 **OBS에 즉시 반영**됨(설정은 저장됨). 예: 가로=오른쪽 + 배치=세로로 쌓기 → 우측 세로 정렬. "📺 오버레이 주소 복사" 버튼은 현재 스타일이 담긴 주소를 복사. 쿼리 파라미터: `?h=right&v=middle&layout=column&size=40&accent=ffcc00&reveal=1`
- **자동분할(보조)**: TTS 바의 "자동분할" 값(0=끔)을 정하면, `/` 로 나눈 구간 중에서도 너무 긴 구간을 그 글자수로 한 번 더 자동으로 나눔. 기본은 꺼짐 — 자막 구분은 `/` 로 직접 하는 게 기본
- **내 프리셋**: 현재 믹서 설정을 이름 붙여 저장

## 개발

```bash
npm install
npm start
```

## 빌드 (Windows exe)

태그를 푸시하면 GitHub Actions가 NSIS 설치본 + 포터블 exe를 빌드해 릴리스에 올립니다.

```bash
git tag v0.1.0 && git push origin v0.1.0
```

로컬 빌드: `npm run dist`

## 참고

- 변조된 목소리를 디스코드·OBS 등 다른 프로그램의 마이크로 넣으려면 [VB-Cable](https://vb-audio.com/Cable/) 설치 후, 이 앱의 출력(모니터) 장치를 `CABLE Input`으로, 해당 프로그램의 마이크를 `CABLE Output`으로 설정하세요.
- 에코 방지를 위해 모니터는 헤드폰 사용을 권장합니다.
